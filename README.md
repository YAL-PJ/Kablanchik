# קבלנצ'יק

כלי לקבלני שיפוצים: תיאור של שיפוץ חדר רחצה הופך להצעת מחיר מפורטת, ללוח זמנים וללוח הזמנות חומרים, עם נוסח הזמנה לספק.

הכלי רץ על המחשב שלך. כשאתה לוחץ "נתח", השרת המקומי מריץ ברקע את ה-CLI של מודל AI שמותקן אצלך (Claude Code, Gemini CLI או Codex), מחובר למנוי שלך. אין מפתחות API ואין עלות מעבר למנוי.

## איך זה בנוי

- **ה-AI רק מבין את הקלט.** הוא הופך תיאור חופשי ל-JSON לפי סכמה קבועה. כל ערך עובר בדיקת טווח לפני שהוא נכנס לטופס, ושדות שה-AI מילא מסומנים בצהוב עד שאתה מאשר.
- **כל מספר מחושב בקוד.** `public/engine.js` הוא פונקציה טהורה: כמויות, פחת, אריזות, מחירים, סדר שלבים, ימי עבודה א'-ה', זמני ייבוש ותאריכי הזמנה. אותו קלט תמיד נותן אותה הצעה.
- **השוואת מודלים.** הכפתור "השווה בין המודלים" מריץ את אותו תיאור על כל המודלים המותקנים במקביל, ומציג טבלה שדה מול שדה עם זמני תגובה. שדות שבהם המודלים לא הסכימו מסומנים, וערכים שנדחו בבדיקת הטווח מוצגים באדום.

```
server.js            שרת מקומי: מגיש את הממשק ומריץ את ה-CLI ברקע
public/index.html    הממשק
public/app.js        לוגיקת הממשק, הפרומפטים ובדיקת התשובות
public/engine.js     מנוע החישוב הדטרמיניסטי
test/engine.test.js  בדיקות למנוע
```

## התקנה

צריך Node 18 ומעלה, ולפחות אחד מה-CLI הבאים, מותקן ומחובר. כדי להשוות צריך לפחות שניים.

| מודל | התקנה | התחברות |
| --- | --- | --- |
| Claude | [Claude Code](https://code.claude.com/docs/en/setup) | להריץ `claude` פעם אחת ולהתחבר עם חשבון Claude |
| Gemini | `npm install -g @google/gemini-cli` ([מדריך](https://geminicli.com/docs/)) | להריץ `gemini` פעם אחת ולבחור התחברות עם חשבון Google |
| ChatGPT | `npm install -g @openai/codex` ([מדריך](https://developers.openai.com/codex)) | להריץ `codex` פעם אחת ולהתחבר עם חשבון ChatGPT |

בדיקה שהכול מחובר: כל אחת מהפקודות האלה צריכה להחזיר תשובה בלי לבקש התחברות.

```
claude -p "say hi"
gemini -p "say hi"
codex exec --skip-git-repo-check "say hi"
```

## הפעלה

```
npm start
```

ואז לפתוח את http://localhost:3000. בהפעלה השרת מדפיס אילו מודלים נמצאו.

הגדרות אופציונליות (משתני סביבה):

- `PORT`: פורט אחר במקום 3000.
- `CLAUDE_BIN`, `GEMINI_BIN`, `CODEX_BIN`: נתיב מלא ל-CLI, אם הוא לא ב-PATH.
- `AI_TIMEOUT_MS`: זמן מרבי לקריאה (ברירת מחדל 180000).

בדיקות המנוע: `npm test`.

## אבטחה ושימוש

- השרת מאזין רק ל-`127.0.0.1`, כך שאף אחד ברשת לא יכול להפעיל דרכו את המנויים שלך.
- בקשות ל-API חייבות להגיע מהממשק עצמו (בדיקת Host וכותרת מותאמת), כדי שאתר זר בדפדפן לא יוכל לשלוח בקשות ל-localhost.
- ה-CLI רצים בתיקייה ריקה (`.ai-workspace`) כדי שלא יקראו את קבצי הפרויקט. Codex רץ ב-sandbox לקריאה בלבד.
- הכלי מיועד לשימוש אישי שלך, על המנויים שלך. אם בעתיד אנשים נוספים ישתמשו בו, כל אחד צריך להתחבר עם מנוי משלו, או לעבור למפתחות API. ראה [התנאים של Claude Code](https://code.claude.com/docs/en/legal-and-compliance).
- כל קריאה נספרת במגבלות השימוש של המנוי הרלוונטי.

## מה עוד לא קיים

- קריאת תוכניות מתמונה או PDF (השלב הבא).
- שמירת פרויקטים בקבצים. כרגע הטופס והמחירון נשמרים ב-localStorage של הדפדפן.
- כיול: הנוסחאות, התפוקות, זמני האספקה והמחירים הם הערכות ברירת מחדל. צריך לכייל אותם מול הצעות אמיתיות של קבלנים לפני שימוש מול לקוח.
- חגים לא נכללים בחישוב ימי העבודה.
